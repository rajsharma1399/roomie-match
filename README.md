## ✨ Key Features

- **🔥 Tinder-Style Discovery Stack:** Swipe through verified potential flatmates with clean card animations and quick preference tags.[cite: 1]
- **🎯 Smart Preference Filters:** Filter matches dynamically by monthly budget and sleep schedules (Night Owl 🌙 vs. Early Bird 🌅).[cite: 1]
- **💬 Interactive Chat Workflow:** Instant connection simulation with active matches and simulated real-time messaging.[cite: 1]
- **🏡 Room & Flat Listings:** Post available rooms or look through active shared apartment listings in your city.[cite: 1]
- **📱 Fully Responsive UI:** Built from the ground up using **Tailwind CSS** to look and feel like a native mobile application.[cite: 1]
