## ✨ Key Features

- **🔥 Tinder-Style Discovery Stack:** Swipe through verified potential flatmates with clean card animations and quick preference tags.
- **🎯 Smart Preference Filters:** Filter matches dynamically by monthly budget and sleep schedules (Night Owl 🌙 vs. Early Bird 🌅).
- **💬 Interactive Chat Workflow:** Instant connection simulation with active matches and simulated real-time messaging.
- **🏡 Room & Flat Listings:** Post available rooms or look through active shared apartment listings in your city.
- **📱 Fully Responsive UI:** Built from the ground up using **Tailwind CSS** to look and feel like a native mobile application.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern JavaScript (ES6+)
- **Styling:** Tailwind CSS (via CDN), Google Fonts (Plus Jakarta Sans)
- **Icons:** Lucide Icons
- **State Management & Persistence:** Browser `localStorage`
- **Hosting:** GitHub Pages
